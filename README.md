# Vitrini

Vitrini es una aplicación móvil Android desarrollada en Kotlin para facilitar el descubrimiento de emprendimientos locales en Costa Rica.

## Tecnologías

- Kotlin
- Android Studio
- Arquitectura MVVM
- Git y GitHub
- Persistencia local planificada

## Estructura del proyecto

- data: fuentes de datos locales o simuladas
- model: clases de datos principales
- repository: acceso centralizado a datos
- ui: pantallas de la aplicación
- viewmodel: lógica de presentación
- utils: constantes y utilidades
